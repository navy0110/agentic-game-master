## Submission copy — English

**What it does**

Agentic Game Master helps tabletop game masters, RPG developers and worldbuilders
create quests, characters and dynamic events for their existing worlds. Users
continue from player choices in the same conversation, with saved facts and open
threads. Spoiler-safe and full GM commands provide different views of the record.

**Who it is for**

Our first users are tabletop GMs preparing sessions in original worlds. We are
testing whether complete, world-aware preparation material helps them run their
next session with less correction work.

**Sponsor integration**

The agent runs on Agentverse, receives requests through Fetch.ai's Agent Chat
Protocol and calls ASI:One for generation. Hosted storage retains campaign
records within the sender/session scope. The public code includes schema-based
generation, validation, bounded retries and read-only commands.

**Feedback and improvement**

Use the recap in IMPROVEMENT-RECAP.md. Attach the actual assigned platform note
and the successful regression screenshot; do not substitute automatic tests for
the required external participant feedback.

**Limitations**

An early preparation assistant, not a live game engine. Model output requires GM
review. Campaign records are session-scoped; cross-session import/sharing and
separate authenticated GM/player roles are not implemented. Generated story
content and full records can reveal secrets. Model availability and latency vary.
